# 决策 —— 为什么这么选、排除了什么

> 答什么：每条决策的结论 + 理由 + 排除了什么。理由变了结论才变；作废的标作废不删。同一条理由也写进它管的那段代码头注释。
> 研究和竞品的证据在 `docs/research.md`。
