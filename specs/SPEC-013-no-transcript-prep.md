# SPEC-013：无讲稿材料的备课

> 答什么：材料没有讲稿（BBC transcript 之类）时怎么备课——句子怎么切、谁在说话从哪来、屏幕上的字怎么保证能读；和带讲稿那条路怎么共存。
> 谁何时读：接一份没讲稿的材料之前；改切割引擎里无讲稿那段、改识别参数之前。
> 怎么变短：规则只写现在的做法；换模型或提示词大改时旧的进改版记录一句话。
> 状态：草稿（方向 owner 2026-11-03/04 拍板；量化背景 `docs/research/2026-11-03-no-transcript-ablation.md`、说话人选型与实测 `docs/research/2026-11-04-speaker-diarization-services.md`）。出处：SPEC-002 R8 的欠账、SPEC-003「还没解决的」；自动验收实现时占号（先全人工，规矩同 SPEC-010）。

## 值不值

- 好处：owner 自备的材料（`materials/original/` 那 8 份 mp3 这类）没有讲稿也能几分钟变课——家长自带材料阶段的地基；说话人照样能标（选型实测：按说话秒数加权 95–96% 对）。
- 代价：一课多两三次大模型调用（合计几分钱）；说话人按句 85–98%（错的绝大多数是半秒一秒的搭腔短句，上屏影响小）；比带讲稿少一层拼写校正，文字凭识别原样（消融实测：拼错 0 个、一字不差约九成）。

## 规则与验收

| # | 规则 | 怎么验收 |
|---|---|---|
| R1 | 适用判据：材料夹里没有 transcript.pdf 也没有 transcript.txt，引擎自动走无讲稿路；有讲稿照走原路（决策 D1、D4 一条不动，四课金样考卷不重刷——识别缓存沿用、对齐算法没碰） | （人工）同一份材料放讲稿、不放讲稿各备一次，两条路都出课 |
| R2 | 识别参数：删掉 speaker_count=2（当年按「两人对话」传的；选型实测它把三课的说话人分离压塌到 48–54%，删后 85–98%）；diarization_enabled 保持开。识别模型不换（qwen-audio-3.0-asr-flash-filetrans，胜过 paraformer-v2） | （人工）无讲稿课每句带说话人标签；带讲稿四课金样考卷全绿 |
| R3 | 拼词：照识别词片的前导空格拼整词，规则与带讲稿路相同（少了「按讲稿重切」那一半） | （人工）无讲稿课屏幕文字抽查 |
| R4 | 巨词（归一化后 ≥20 字符）：先交备课已有的大模型加空格（deepseek-flash，一课最多一次调用、几分钱），**校验切完的字母序列必须和原来一字不差**；不过关退词频切法（wordfreq 动态规划、不认识的段按字母数罚——实测 7/9），再不行原样保留。wordfreq 补进 requirements.txt（本机已装） | （人工）快餐课重放：9 处巨词全部恢复成可读句子 |
| R5 | 并半句：只看标点——前句以逗号结尾、或后句以小写字母开头就并（并时去掉识别点在半句处的句号），不看说话人（实测四课拆碎句 7/8/8/10 → 2/6/3/4） | （人工）四课重放对比拆碎句数 |
| R6 | 说话人三步：①每句的说话人＝识别给的 speaker_id；②「编号归并成人＋起名」交大模型（提示词住代码里、按批抽查调，规矩同 SPEC-006 的点词提示词），五条铁律——被谈到的人不是说话人；拿不准优先并进已有的人；对话中段的编号是拆分、不是预告；能确认才真名、但凡有一点不够确认就 Role A、Role B（owner 2026-11-04 定）；片头片尾的短编号才可能是 promo／音乐。实测四课按句 85/94/81/97%；③人工修正层 speaker_manual.json 沿用 | （人工）四课试跑＋owner 人耳抽查 19 句「两家服务与金样相左」处（清单在选型报告，抽查兼修金样） |
| R7 | 片头预告：忠实还原、一句不剔（owner 2026-11-04：「直接从语义层面去拆解」）；挑生词和预热词的提示词加「只挑这一课正题的词，忽略节目预告、订阅推广那类语句」（带讲稿课也适用，无害） | （人工）无讲稿课的生词表、预热词里没有预告的词 |
| R8 | 质量报告：无讲稿课不出「对上率」（没有讲稿可对），改出巨词恢复 N 处、并句 M 处、说话人几位、编号归并表；timeline 的 engine 字段带升了的版本号 | （人工）报告一眼能看懂，没有吓人的 0% |
| R9 | 网站接线：上传没讲稿的材料点备课，不再报「把讲稿粘进来」；材料状态机、备课时长、花费与带讲稿同级（分钟级、一课几毛）；上传面板不再说「要备课就得有讲稿」 | （人工）真传一份无讲稿 mp3 走完上传→备课→听课 |
| R10 | 无讲稿考卷：实现时占号——四课离线重放（识别吃试跑缓存、大模型吃缓存，不联网不花钱），逐句对 free 金样（首次跑出＋人耳修正后锁定）；咬人自检同 SPEC-012 R6 的精神 | 实现时占 A 号 |

## 决策依据

- 消融量化（2026-11-03 报告）：没讲稿差在说话人、片头预告、巨词、碎句四件；屏幕文字本身九成以上不差、识别拼错 0 个——所以不为「换识别模型」折腾。
- 说话人选型（2026-11-04 报告）：最大意外是自家传的 speaker_count=2 在帮倒忙；现模型去参数四课全面小胜 paraformer-v2，故不换模型、不加服务。
- 编号起名三轮试（2026-11-04，探针在 ablation/）：第一轮大模型把「被谈到的人」发明成说话人（快餐课 98%→78%）；第二轮收紧后矫枉过正、把中段拆分标成 promo；第三轮给位置统计＋「中段编号是拆分不是预告」后，四课 85/94/81/97%——铁律照第三轮写进 R6。
- owner 三条方向（2026-11-04）：要区分说话人（换手处是句界，利于语义切割）；片头预告忠实还原；名字能确认才真名、拿不准 Role A、Role B。
