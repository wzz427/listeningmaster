# SPEC-003：语音识别、对齐讲稿、切成句子

> 答什么：一段录音怎么变成「谁在什么时候说了哪句话」：用哪个识别、讲稿怎么用、说话人从哪来、句子按什么切。句子起止点再怎么修准归 SPEC-004。
> 谁何时读：接一种新格式的材料（新的讲稿样式、没讲稿、别的播客）之前；改 `pipeline/asr_probe.py`、`transcript.py`、`align.py` 之前。
> 怎么变短：规则表只写现在的做法；换了识别或对齐办法，旧的写进改版记录一句话。
> 状态：开发中（有 BBC 讲稿的材料已跑通；没讲稿的没试过）。出处：`demand.md` 第 1 条；总流程 `specs/SPEC-002-prep-pipeline.md` 第 2、3 步。

## 值不值

- 好处：后面每一步（边界、中文、点词、分段）都站在这一步上。句子切错了、说话人标错了、屏幕上的字和录音对不上，孩子会以为是自己听错了。
- 代价：识别一集约 0.08 元、12 秒；对齐不花钱、不到 1 秒。

## 规则与验收

| # | 规则 | 怎么验收 |
|---|---|---|
| R1 | 识别用百炼的录音文件识别 `qwen-audio-3.0-asr-flash-filetrans`（决策 D2）：英文可用，句级和词级时间固定给出，单文件上限 12 小时。它只收公网地址，所以先用百炼 SDK 的临时存储把本地的 16k 单声道 wav 传上去，请求头里打开 `X-DashScope-OssResourceResolve`（`docs/lessons.md`） | 第一集：103 句、969 个词片，每个词都有起止时间；花费约 0.08 元 |
| R2 | 识别给的是词片（Georg + ie、I + ' + m），以空格开头的算新词，拼回整词再用 | 第一集拼成 845 个词 |
| R3 | 说话人用讲稿里的标注，不用识别的说话人分离（决策 D4） | 第一集识别的说话人分离 103 句里 96 句判成同一人，不可用；用讲稿后正文 89 句抽查全对 |
| R4 | 屏幕上显示识别出的原话，讲稿只用来校正拼写和大小写（决策 D1）：两边对上的词换成讲稿的写法，保留识别的标点；对不上的照识别原样 | `align_report.md` 里讲稿对上的比例：第一集 720/788（91%）；对不上的是片头片尾、口头语，以及讲稿不是逐字稿的地方 |
| R5 | 对齐：两边都切成词、做同样的归一化（只留字母数字和撇号），求最长匹配。对上的词继承讲稿那一轮话的说话人；中间没对上的跟前一个词走；话轮号应该只增不减，个别词（连续不超过 2 个）配到更早的一轮当噪声改回来 | 第一集修正噪声 0 个；没修之前 Neil 那句开头的 so 配到 Georgie 更早说的 so，平白切出一个半秒的碎句 |
| R6 | 片头片尾：开头、结尾整段没对上讲稿的，标成「片头片尾」，不算正文；播放器单独标出（SPEC-001 R11） | 第一集 9 句片头片尾、89 句正文 |
| R7 | 切句以识别给的句子为底，再做两件事：一句话里换了人，就从换人的那个词切开；同一个说话人的半句（上一句以逗号结尾，或者下一句以小写字母开头）并回去，并句时去掉识别在半句处点的句号。重听的单位是一个完整意思，半句话没法练 | 第一集识别 103 句 → 按说话人切开、并回 10 处碎片后 98 句 |
| R8 | 词的时间只用来在重听时高亮正在读的词，不拿来切单个词：识别给的词时间偏晚，而且每个词偏得不一样（决策 D24，SPEC-007 R6） | SPEC-007 |
| R9 | 写 `align_report.md`：识别和讲稿各多少词、对上多少、修了几处噪声、并了几处碎片、正文和片头片尾各几句，加整张时间轴 | 第一集的报告在 `lessons/260821/align_report.md` |

## 讲稿怎么读

BBC 的讲稿 PDF（`pipeline/transcript.py`）：去掉页眉页脚和版权声明；说话人行的特征是一两个词、首字母大写、没有句末标点、反复出现；其余是这个人说的话。别的格式的讲稿要先改这个程序，改完抽几轮话看对不对。

## 还没解决的

- **没讲稿的材料**（SPEC-002 R8）：说话人没有来源（识别的分离不可用），拼写只能照识别。可能的路：换一个说话人分离可用的识别、或者先不分说话人。试之前先找一份没讲稿的材料做实验。
- **粘在一起的词**：第一集识别把 It means 粘成 Itmeans，对齐没拆开。出现第二次再修（`docs/debts.md`）。
- **太长的句子**：第一集精修边界后最长 11.54 秒（第 55 句 Caffeine is that chemical…），10 秒以上的有 3 句。要不要在逗号处拆，等孩子试用看他在长句上卡不卡。

## 不确定的环节，先做的实验（2026-09-12）

- 输入：`materials/260821/` 的 6 分 02 秒音频 + 讲稿 PDF。做法：百炼录音文件识别，再和讲稿逐词对齐。输出：`lessons/260821/timeline.json`、`align_report.md`。
- 结果：识别 103 句、969 个词片，词级时间齐全；和讲稿对上 91%；说话人分离不可用，改用讲稿；正文 89 句，句长中位 1.92 秒、最短 0.20 秒、最长 11.36 秒；句与句之间最小间隔 0.08 秒，没有重叠。
- 结论：时间轴能拿来做「回到句首」；起止点准不准要用耳朵验（后来发展成 SPEC-004）。

## 决策依据

- 先识别再对齐讲稿，而不是把讲稿喂给识别当提示：讲稿不是逐字稿，喂进去容易编出没说的话（`docs/research.md` 四）。
- 不在本地跑识别模型（WhisperX 等）：要装环境、显存只有 4GB，家长那边也复制不了（决策 D2）。
